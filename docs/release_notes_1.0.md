# Release 1.0 notes

Release 1.0 consolidates the previously separate digital-edition, website, and TEI packages into a single Git-friendly repository.

## Included
- Static GitHub Pages site at repository root.
- Password-gated internal research interface.
- Corrected responsive synopsis with configurable witness set/order and organizing witness.
- Five reconstructed witnesses plus De Michelis reconstruction.
- Structure-aware 22/27/24 protocol organizations.
- Interactive transmission and variation maps.
- Corpus-wide named-entity index and distant-reading atlas, spatial view, co-occurrence network, concept profiles, and similarity matrix.
- Protocol-internal anatomy view.
- Full TEI corpus and one-click TEI ZIP download.
- Editorial audit and source-anomaly records.

## Repository reduction
Duplicated web JSON, duplicated site TEI, OCR scratch material, page renders, and intermediate reconstruction artifacts are excluded. This keeps the repository compact without removing anything needed for presentation, browsing, TEI reuse, or editorial audit.
