# Release 2.0 (provisional)

This release is the first implementation of the target system architecture. It remains a De Michelis-based temporary research environment.

## Main changes
- De Michelis is explicitly presented as a reconstruction/reference text, not as a documentary K transcription.
- K, A1, A2, N and B are explicitly marked **provisional-derived**.
- The two paired historical source notes marked `(*)` and `(**)` in Protocol II are extracted from the running text into a separate source-note layer and shown from clickable markers.
- Unit-level provenance flags mark places where De Michelis explicitly records long K omissions (`usque ad`), preparing for span-level provenance.
- The transmission diagram is labelled as the **De Michelis working model**, not the final project stemma.
- `SYSTEM_ARCHITECTURE_v0.1.md` and `architecture-manifest.json` define the migration path to documentary witness transcriptions.

## Deliberately not done yet
- No final Sabrina transmission model is asserted.
- No documentary witness scans are ingested in this release.
- Provisional reconstructions remain available for tool testing, synopsis development, and research orientation.
