# Research annotation layer

Research annotations are interpretive, researcher-authored claims and must remain separate from documentary transcription and De Michelis's critical apparatus.

The web interface stores annotations in the browser (`localStorage`) so a researcher can experiment without changing repository files. Each record stores witness/view, structural unit, selected quotation, optional character offsets when recoverable, canonical locus IDs when inferable, controlled tags, note text, timestamp, and status.

Use **Export JSON** for round-trip editing and **Export TEI** for preservation. Annotations can later be reviewed and committed to `tei/analysis/research_annotations.xml`.
