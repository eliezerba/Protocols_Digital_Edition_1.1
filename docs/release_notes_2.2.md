# Version 2.2

This release prepares the provisional De Michelis workbench for documentary witness ingestion without yet ingesting the witness scans.

- Canonical witness-independent locus map: **3,603 loci** derived from apparatus anchors, with provisional mappings into the 22/27/24 structures.
- Documentary witness TEI contract: template, Relax NG schema, validation helper, and ingestion guide.
- Research annotation layer: controlled vocabulary, local-first annotation UI, JSON/TEI export/import, and TEI stand-off target.
- New Research workspace for inspecting locus mappings and researcher annotations.
- Close reading now offers selection-based research annotation.
- Architecture documentation updated to v0.2.

The current K/A1/A2/N/B texts remain provisional and derived from De Michelis.
