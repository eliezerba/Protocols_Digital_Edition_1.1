# Release 1.1 notes

Release 1.1 adds a contextual in-site research guide.

- A persistent circular **i / Guide** control appears in the main navigation.
- The guide explains the purpose of the current page and the main actions available there.
- A project-wide map inside the guide explains Read, Compare, Tradition, Search, Index, Distant Reading, Method, and TEI access.
- All guide routes are live links back into the edition.
- The guide is keyboard accessible, closes with Escape or by selecting the backdrop, and adapts to small screens.

No editorial data, witness reconstruction, apparatus, NER layer, or TEI content was changed in this release.
